# @stylai/api

Runnable Fastify foundation with an optional restricted private-transaction pool. GET /health/live -> 200; GET /health/ready requires the expected Supabase foundation RPC **and** the restricted database role/ACL/version probe, returning 503 when either is missing/unavailable. This does not prove product readiness. See docs/operations/private-database-boundary.md and docs/SUPABASE-SETUP.md. App auth/domain handlers remain pending. Unimplemented /v1 routes return 503 with the existing error envelope. The Asaas webhook is deliberately NOT acknowledged. Root docs/START-HERE.md explains setup and next work.
